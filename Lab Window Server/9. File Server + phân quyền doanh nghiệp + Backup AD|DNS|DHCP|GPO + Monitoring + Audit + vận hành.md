# CHƯƠNG 18 — FILE SERVER + PHÂN QUYỀN DOANH NGHIỆP
## 18.1. Không nên dùng DC làm File Server

Đây là nguyên tắc đầu tiên.

Hiện tại bạn có:
```
DC01
192.168.90.10
```
Không nên lưu dữ liệu công ty trực tiếp trên:
```
C:\Shares
```
của DC.

Nên bổ sung một server riêng:
```
FS01
192.168.90.20
```
Ví dụ:
```
DC01 = 192.168.90.10
FS01 = 192.168.90.20
```
FS01 có thể là:

- Windows Server vật lý
- Windows Server VM trên ESXi
- Windows Server chạy trên server IBM hiện tại nếu tài nguyên cho phép

Nếu bạn đang có ESXi thì mình khuyên tạo:
```
VM: FS01
CPU: 4 vCPU
RAM: 8–16 GB
OS Disk: 100 GB
Data Disk: tùy dung lượng
```

## 18.2. Join FS01 vào Domain

Trên FS01:
```

→ Local Server
→ Computer Name
→ Change
```
Chọn:
```
Domain:
company.local
```
Nhập tài khoản Domain Admin.

Restart.

Sau đó kiểm tra:
```
whoami
```
và:
```
systeminfo
```
