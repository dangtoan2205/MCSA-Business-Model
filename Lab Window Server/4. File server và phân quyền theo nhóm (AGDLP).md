File Server và phân quyền theo nhóm (AGDLP).
----

Với mô hình hiện tại:
```
Domain:       seta-international.vn
DC01:         192.168.90.10
Gateway:      192.168.90.254
DHCP:         Windows Server
Cisco 2960S:  mạng nội bộ
```

> Mục tiêu: là tạo hệ thống thư mục dùng chung, trong đó User không được cấp quyền trực tiếp mà đi qua Group.

> Lưu ý quan trọng: Trong mô hình doanh nghiệp thực tế, nên có một File Server riêng (FS01), không lưu dữ liệu người dùng trên DC01. Nếu hiện tại mới có DC01 thì có thể thực hành trên DC01, sau này chuyển File Server sang FS01.

9.16. Share Permission

Ở đây bạn sẽ thấy:

Everyone

Có thể thiết kế theo nguyên tắc:

Everyone → Full Control

ở Share Permission, trong khi NTFS mới là nơi kiểm soát quyền thực tế.

Đây là cách phổ biến giúp quản lý dễ hơn:

SMB Share:
Everyone → Full Control


NTFS:
DLG_IT_RW → Modify

Khi đó NTFS là lớp kiểm soát chính.

Tuy nhiên, nếu đây là môi trường production với yêu cầu bảo mật cao, ta có thể siết Share Permission theo nhóm. Trong tài liệu này mình ưu tiên mô hình dễ quản trị và dễ troubleshooting.

Apply
