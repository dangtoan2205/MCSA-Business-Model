# A. Chuẩn bị trước khi Join Domain

Đây là phần **rất quan trọng**. Không nên vội Join Domain.

Trên PC Windows 10/11 cần kiểm tra:

## 1. Kiểm tra IP

Mở CMD:
```
ipconfig /all
```
Bạn phải thấy tương tự:
```
IPv4 Address . . . . . : 192.168.90.xxx
Subnet Mask . . . . . : 255.255.255.0
Default Gateway . . . : 192.168.90.254
DHCP Server . . . . . : 192.168.90.10
DNS Servers . . . . . : 192.168.90.10
```

**Đặc biệt:**

DNS phải là:
```
192.168.90.10
```
Không được là:
```
192.168.90.254
8.8.8.8
1.1.1.1
```
Đây là một trong những nguyên nhân phổ biến nhất khiến Windows không Join Domain được.

## 2. Kiểm tra DNS

Trên PC chạy:
```
nslookup seta-international.vn
```
Kết quả phải cho thấy DNS Server:
```
Server:  dc01.seta-international.vn
Address: 192.168.90.10
```
Sau đó:
```
nslookup dc01.seta-international.vn
```
Phải phân giải được về:
```
192.168.90.10
```

## 3. Kiểm tra kết nối tới Domain Controller

Trên PC:
```
ping 192.168.90.10
```
Phải nhận được Reply.

Tiếp tục:
```
ping dc01.seta-international.vn
```
Nếu DNS đúng thì cũng phải Reply.

Sau đó:
```
nltest /dsgetdc:seta-international.vn
```
Nếu thành công, bạn sẽ thấy thông tin Domain Controller.

Ví dụ:
```
DC: \\DC01.seta-international.vn
Address: \\192.168.90.10
Domain Name: seta-international.vn
```
**Chỉ khi những bước này OK mới Join Domain.**

----
⚠️ Một điểm rất quan trọng về mục tiêu "Join Domain mới được Internet"
----

Đến đây **chưa được phép kết luận rằng máy Join Domain mới có Internet**.

AD/GPO có thể:
- Quản lý User.
- Quản lý Computer.
- Áp dụng chính sách.
- Kiểm soát cấu hình Windows.
- Phân quyền File Server.
- Map Drive.
- Quản lý Defender/Firewall.

Nhưng **AD không tự động biến pfSense thành bộ lọc "chỉ máy Join Domain mới được Internet"**.

Với mô hình của bạn, chúng ta sẽ xây dựng phần đó ở các chương sau theo hướng:
```
                 INTERNET
                     │
                    VNPT
                     │
               pfSense Firewall
              192.168.90.254
                     │
                Cisco 2960S
                     │
        ┌────────────┼─────────────┐
        │            │             │
      VLAN 10      VLAN 20       VLAN 30
       User       Accounting       Sales
        │            │             │
       PC           PC            PC
        │
        └────── AD Authentication ──────┐
                                         │
                                  DC01 / NPS
                                  192.168.90.10
```
Sau khi hoàn thiện **AD + GPO + NPS/RADIUS + VLAN + Cisco 802.1X**, chúng ta mới có thể tiến tới mô hình kiểm soát truy cập mạng chặt chẽ hơn.
