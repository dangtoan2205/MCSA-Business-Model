seta-international.vn

| OU                   | Mục đích                                                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Servers**          | Chứa các máy chủ thành viên (File Server, Print Server, Application Server...). Domain Controller vẫn ở OU **Domain Controllers** mặc định. |
| **Workstations**     | Chứa tất cả máy tính người dùng sau khi Join Domain (PC, Laptop). Sau này sẽ áp dụng GPO cho máy tính tại đây.                              |
| **Users-Company**    | Chứa tài khoản người dùng của doanh nghiệp. Không sử dụng container **Users** mặc định để dễ quản lý và áp dụng GPO.                        |
| **Groups**           | Chứa các Security Group và Distribution Group dùng để phân quyền.                                                                           |
| **FileServers**      | Dùng để quản lý các File Server hoặc các chính sách liên quan đến chia sẻ dữ liệu (tùy quy mô).                                             |
| **Printers**         | Quản lý các đối tượng máy in hoặc các GPO dành cho máy in.                                                                                  |
| **Security**         | Chứa các tài khoản, nhóm hoặc OU phục vụ các chính sách bảo mật đặc biệt.                                                                   |
| **Service Accounts** | Chứa các tài khoản dịch vụ (ví dụ dùng cho SQL Server, Backup, ứng dụng...), không dùng để đăng nhập tương tác.                             |
| **Administration**   | Chứa tài khoản quản trị viên và các nhóm quản trị riêng, tách biệt với người dùng thông thường.                                             |

**Xóa OU**

<img width="1100" height="502" alt="image" src="https://github.com/user-attachments/assets/a03b9dab-f793-4459-8ee8-a8b7a65041cb" />

Lỗi trong ảnh là:

> **You do not have sufficient privileges to delete OU Cap 1, or this object is protected from accidental deletion.**

Thông thường, đây **không phải do thiếu quyền**, mà do OU đang được bật tính năng **Protect object from accidental deletion** (Bảo vệ khỏi xóa nhầm).

**Cách 1: Bỏ bảo vệ rồi xóa (Khuyến nghị)**

**Bước 1. Hiển thị tab Advanced Features**

Mở **Active Directory Users and Computers**.

Trên thanh menu chọn:
```
View
    ↓
Advanced Features
```

Đảm bảo có dấu ✓ trước **Advanced Features**.

**Bước 2. Mở Properties của OU**

```
Chuột phải vào: OU Cap 1

↓

Properties
```

**Bước 3. Bỏ tùy chọn bảo vệ**

Chọn tab: Object

Bỏ chọn: Protect object from accidental deletion

Nhấn: Apply -> OK

**Bước 4. Xóa OU**

Chuột phải vào OU: Delete

Lúc này sẽ xóa được.

**Nếu không thấy tab Object**

Đó là do chưa bật **Advanced Features**.

Hãy kiểm tra lại:

```
View
    ☑ Advanced Features
```
Sau đó đóng và mở lại cửa sổ Properties của OU.

**Cách 2: Dùng PowerShell**

Nếu muốn dùng PowerShell:

```
Get-ADOrganizationalUnit -Filter * | Select Name,ProtectedFromAccidentalDeletion
```
Kiểm tra OU đang được bảo vệ.

Bỏ bảo vệ:
```
Set-ADOrganizationalUnit `
-Identity "OU=OU Cap 1,DC=seta-international,DC=vn" `
-ProtectedFromAccidentalDeletion $false
```
Sau đó xóa:
```
Remove-ADOrganizationalUnit `
-Identity "OU=OU Cap 1,DC=seta-international,DC=vn"
```

# 7. Redirect Computer Container

Hiện tại máy Join Domain sẽ vào

```
CN=Computers
```

Không nên.

Mở CMD Administrator

```
redircmp "OU=User,OU=Workstations,DC=seta-international,DC=vn"
```

Nếu bạn tạo OU khác thì thay cho phù hợp.

Sau này mọi máy Join Domain sẽ tự động vào OU này.

# 8. Redirect User Container

```
redirusr "OU=IT,OU=Users,DC=seta-international,DC=vn"
```

Hoặc OU phù hợp với quy trình của bạn.
