# PHẦN 14 — Một vấn đề quan trọng với VLAN 50

# ⚠️ Nhưng trước khi bạn làm theo toàn bộ phần trên

Có **một thay đổi kiến trúc rất quan trọng** mà mình khuyên bạn thực hiện **trước khi cấu hình Dynamic VLAN**:

Hiện tại bạn đang có:
```
VLAN 10
VLAN 20
VLAN 30
VLAN 40
VLAN 50
```
nhưng tất cả vẫn nằm trong:
```
192.168.90.0/24
```
Mình không khuyên tiếp tục cấu hình Dynamic VLAN trên mô hình này nếu mục tiêu cuối cùng là mạng doanh nghiệp.

Nên chuyển thành:
```
VLAN 10 → 192.168.10.0/24
VLAN 20 → 192.168.20.0/24
VLAN 30 → 192.168.30.0/24
VLAN 40 → 192.168.40.0/24
VLAN 50 → 192.168.50.0/24
VLAN 90 → 192.168.90.0/24
```
và giữ:
```
DC01 = 192.168.90.10
pfSense VLAN90 = 192.168.90.254
```
**Sau đó mới triển khai 802.1X + Dynamic VLAN.**

Nếu bạn muốn giữ nguyên `192.168.90.0/24` cho toàn bộ hệ thống hiện tại thì vẫn có thể làm lab 802.1X, nhưng nó **không phải kiến trúc VLAN doanh nghiệp hoàn chỉnh**.

**Vì vậy thứ tự triển khai thực tế mình đề xuất cho hệ thống của bạn là**:
```
HIỆN TẠI
192.168.90.0/24
        │
        ▼
[Chuyển sang VLAN + subnet]
        │
        ▼
pfSense VLAN 10/20/30/40/50/90
        │
        ▼
Cisco 2960S Trunk
        │
        ▼
DHCP từng VLAN
        │
        ▼
AD/DNS 192.168.90.10
        │
        ▼
AD CS
        │
        ▼
Computer Certificate
        │
        ▼
NPS
        │
        ▼
EAP-TLS
        │
        ▼
802.1X
        │
        ▼
Dynamic VLAN
        │
        ▼
pfSense Firewall
        │
        ▼
Internet
```

**Đừng chuyển** IP DC01 `192.168.90.10` sang `VLAN 10/20/30/50`. Hãy để `DC01` ở `VLAN 90` – `Server/Management`. 
Đây sẽ là nền tảng tốt để sau đó mình hướng dẫn bạn `cấu hình pfSense + Cisco 2960S VLAN/Trunk + DHCP từng VLAN` mà không làm mất kết nối `Domain Controller`.
